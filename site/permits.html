Permits

This page facilitates the organization of inclusive play by outlining the essential permit requirements and application processes for parent-led athletic events across NYC. If you're a parent and want to organize outdoor events for your child, you'll need a permit. Unlike recreation centers, however, only one permit is needed for the entire group. This is assuming you want the children to have full, uninterrupted access to the space. If not, then a different permit type is needed. See the info below on how to get a permit.

  • To get a permit:
    • 1. View this link for info on Special Events Permits.
      • Click on the links on the left side to view more info about Special Events Permits, including more information about concessions (pricing included)
      • $25 to process
    • 2. On the right side, log in if you have an NYC Parks account or create an account to request for a permit
